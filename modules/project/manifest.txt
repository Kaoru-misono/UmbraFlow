# The offline Project Kit boundary owns declared source inputs, generated
# artifact closures, complete digest manifests and immutable releases. A
# generated artifact is a closure member; a hand-written input is not, and is
# pinned by digest as an input instead.

# task, because the kit writes the genesis RuntimeArtifact at scaffold
# time and RUNS the trusted RuntimeModel parser at check and build time.
# Both are the runtime's own bytes rather than the kit's: the file names,
# the format numbers, the genesis document, and the one embedded parser
# `project check` executes so that a model a live session would refuse is
# refused offline. The kit still interprets no RuntimeModel semantics in
# C++ of its own -- it calls the interpreter instead of restating it.
private = image json schema task

# speak for it. Everything platform-specific about doing that is under
# platform/, on the same terms as every other boundary in this repository.
